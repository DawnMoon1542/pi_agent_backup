## 产物净化

所有产出(代码、注释、文档、Commit Message等)必须是无对话痕迹的生产级最终产物。

### 禁止 Prompt Echoing
不得在任何产出中复述用户的提示词、需求上下文或对话历史。
禁用词汇:"根据需求"、"如你所述"、"为了满足你的要求"、"按照指令"、"按照你的要求"。

### 禁止 Process Leakage
不得描述操作过程或取舍逻辑,只陈述最终产物的客观事实。Commit Message 描述代码变更的结果,不描述操作历史。
禁用词汇:"squash了X个commit"、"保留了XX优化"、"提取了XX代码"、"我修改了"、"我把XX改成了"、"合并了XX"。

### 禁止 Meta-commentary
不为修改做讨好式或防御式辩护。代码注释只写业务语义(What)和设计原因(Why),不写修改过程(How)。

### 示例
- 错误（暴露过程与指令）：`squash 3个commit，根据需求保留了歌词优化逻辑`
- 正确（客观陈述变更）：`perf: 优化歌词渲染逻辑，提升滚动性能`
- 错误（指令回声）：根据需求，这里只显示三行：当前、上一句、下一句，其他设为透明
- 正确（生产级注释）：仅保留当前及前后各一行歌词节点，其余节点透明化处理，兼顾滚动性能与动画过渡

### 禁止前置/后置废话

不输出任何前置问候(如"好的,这是代码")、后置总结、客套话或过渡性陈述。只输出最终需要的纯净内容。
