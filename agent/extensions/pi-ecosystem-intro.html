Pi Coding Agent — Extensions 与 Skills 完整介绍

从扩展层到知识层，完整梳理 pi coding agent 的 16 个扩展模块与 22 个技能指令

pi-ecosystem-intro.md 2026-05-18 ~10 分钟阅读

背景

Pi Coding Agent 是一个可高度扩展的 AI 编码助手框架。本文档系统梳理其两大核心扩展机制：Extensions（运行时增强层）与 Skills（知识与指令层），涵盖 16 个扩展模块与 22 个技能指令，从技术实现、功能用途到架构关系进行全面介绍。

Extensions — 运行时增强层

Extensions 通过 Pi 扩展 API 直接注册 hook、工具、命令和 provider，在运行时改变 agent 的行为、外观和能力边界。按功能域分为 5 个分类目录，共 16 个独立扩展模块（含 4 个 npm 子项目）。

整体架构关系

要点

Extensions 提供"怎么做"的运行时能力，通过 Pi 扩展 API 注册 hook、工具、命令、provider 直接改变 agent 的行为和外观。Skills 提供"做什么"的方法论指导，以 Markdown 文档形式通过 $skill:name 或自动匹配注入到 agent 上下文中。两者相辅相成，共同构成 pi coding agent 完整的可扩展生态。

Extensions 与 Skills 之间通过两个扩展建立桥梁：

  • skill-dollar-reference — 为 skill 引用提供编辑器自动补全和 agent 启动前的路径注入能力
  • pi-subagents — 支持将 skill 预加载到子代理上下文中

架构决策

Extensions 作为运行时增强层直接操作 agent 实例，Skills 作为知识指令层指导 agent 行为。这种分层设计使得能力扩展与方法论指导解耦——可以独立升级扩展而不影响技能集，也可以独立优化技能文档而不修改运行时代码。
